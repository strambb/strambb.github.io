# My 2028 CPTS Plan

Alongside my current line of work I plan to achieve a CPTS certification on HTB latest 2028. 
For this goal, I pursuit the Penetration Tester learning path on [HTB Academy](https://academy.hackthebox.com/app/paths/16). The learning path will be complemented by HTB and HMV boxes which I try to break in, before and after reading / watching the write-ups. 


## The Plan 
All in all the plan looks like this: 
- 2 Modules completed per month
- One summarizing blog post per module including cheat sheets serving as my notes for the exam
- One box per week including write-up
All this with the target scope of 8-10 hours per week.
